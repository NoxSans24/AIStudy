# AI StudyMate

AI StudyMate adalah aplikasi pendamping belajar untuk mahasiswa IT/Informatika.

## Platform
- Web: React + TypeScript + Vite
- Android: Flutter
- Backend: Python + FastAPI
- Database: PostgreSQL

## Status
Tahap persiapan dan pengembangan awal.

## Struktur
- apps/web: aplikasi web
- apps/mobile: aplikasi Android
- apps/api: backend API
- docs: dokumentasi proyek
